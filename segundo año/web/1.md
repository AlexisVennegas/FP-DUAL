# Estructura básica de HTML

HTML es un lenguaje de marcado que define la estructura y el contenido de una página web.

- `<!DOCTYPE html>`: declara el tipo de documento.
- `<html>`: elemento raíz del documento.
- `<head>`: contiene los metadatos.
- `<body>`: contiene el contenido visible.

# Etiquetas básicas de HTML

- `<p>`: define párrafos.
- `<a href>`: crea enlaces.
- `<img>`: inserta imágenes.
- `<ul>`, `<ol>` y `<li>`: crean listas.
- `<div>`: agrupa contenido en divisiones.

# CSS

CSS define el estilo y la presentación de una página HTML.

## Vinculación con HTML

Para enlazar una hoja de estilos externa, se utiliza esta etiqueta dentro de `<head>`:

```html
<link rel="stylesheet" href="style.css">
```
